## Hi, I'm Yavuz Kerem 👋

I'm a computer engineering student. Lately I've been working on computer vision (object detection and tracking) and on applications built around machine learning models and LLMs. I like taking a project all the way from the model to something people can actually use.

### Projects

| Project | What it is | Stack |
|---|---|---|
| [Anti-UAV Drone Tracking](https://github.com/yavuzkrm/Anti-UAV-Drone-Tracking) | Tracks drones in infrared video. Compares a Kalman filter tracker I wrote with ByteTrack on the Anti-UAV dataset. | Python, YOLOv8, NumPy |
| [Anti-UAV Drone Detection](https://github.com/yavuzkrm/Anti-UAV-Drone-Detection) | Trains and evaluates the YOLO detector used in the tracking project, on both infrared and visible video. | Python, YOLOv8 |
| [NextWatch](https://github.com/yavuzkrm/Full-stack-content-based-movie-recommendation-system) | Content-based movie recommendation site. Combines TF-IDF similarity with Bayesian ranking. [Live demo](https://film-recommendation-system-production-29d8.up.railway.app) | Flask, MySQL, scikit-learn |
| [RAG Project](https://github.com/yavuzkrm/rag-project) | Ask questions about your own PDF/DOCX/TXT files with a local LLM. | LangChain, ChromaDB, Ollama, Streamlit |
| [Ritim](https://github.com/yavuzkrm/ritim) | Offline tracker for recurring tasks and medication, designed for older users. [Open the app](https://yavuzkrm.github.io/ritim/) | HTML, JavaScript, PWA |
| [Günce](https://github.com/yavuzkrm/gunce) | Personal and shared journals on a monthly calendar. | Node.js, Express, SQLite |
| [Tavla Online](https://github.com/yavuzkrm/tavla-online) | Real-time two-player backgammon with room codes. | TypeScript, React, Socket.IO |
