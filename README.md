### Projects

**[Anti-UAV Drone Tracking](https://github.com/yavuzkrm/Anti-UAV-Drone-Tracking)**\
Single-drone tracking in infrared video. Compares my own Kalman Filter tracker with ByteTrack on the Anti-UAV dataset, including runs where the detector only processes every k-th frame.\
`Python` `YOLOv8` `NumPy`

**[Anti-UAV Drone Detection](https://github.com/yavuzkrm/Anti-UAV-Drone-Detection)**\
YOLOv8 drone detector for infrared and visible video. Uses a recording-based split to avoid data leakage and compares a joint model with per-sensor models.\
`Python` `YOLOv8` `PyTorch`

**[NextWatch](https://github.com/yavuzkrm/Full-stack-content-based-movie-recommendation-system)**\
Content-based movie recommendation web app using TF-IDF similarity and Bayesian re-ranking. [Live demo](https://film-recommendation-system-production-29d8.up.railway.app/)\
